## Name

Favoright

## Short description

Finds favorites that no longer work and makes favorite folders easier to spot.

## Description

Favoright checks every favorite in Microsoft Edge and tells you which ones no
longer work, so you can tidy up years of saved links with confidence.

BROKEN FAVORITES REPORT
• Checks each favorite's web address and records the HTTP response.
• Lists suspect favorites first: no response, timeouts, and errors such as
  404 Not Found or 410 Gone.
• Shows where each favorite lives (Favorites bar or folder path), its name,
  address, response code, the date it was added and the date it was last used.
• Optionally shows how many times you visited each favorite, from your
  browsing history (asks for permission only when you turn it on).
• Choose suspect favorites only, or all favorites with suspect ones first.
• Reader mode favorites are checked through the page they open.
• Save the report as a standalone HTML file.

Sites that answer but restrict access (sign-in required, rate limiting) count
as working, not broken. "Suspect" is not proof a page is gone: intranet
addresses, VPN-only sites and temporary outages can show up too, so review
before deleting.

EASIER-TO-SEE FOLDERS
Edge's folder icon can be hard to tell apart from a favorite. Turn on one
setting and Favoright puts 📁 at the start of every folder name, except
folders sitting directly on the Favorites bar. Names that already start with
📁 are left alone. Turn it off and the glyph is removed again.

PRIVATE BY DESIGN
• No accounts, analytics, ads or tracking. The developer runs no server.
• Checks are anonymous requests straight to each favorite's own site, with no
  cookies and no referrer.
• Everything stays on your computer.

Free. Source code: https://github.com/stevencohn/Favoright
